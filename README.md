# bird-test
This is an test i have designed for expanding my skills, I plan to leave as is for now and i will allow anyone to mod or take code from this project for any reason as long as i get credited!
What this software does is turn yourself into an cockatoo with face tracking and desktops with 4GBs of ram or more can run it, You may need an Powerful CPU or NPU! I got 26-24 FPS on an Macbook Air 2014 with 4GBs of RAM and 20-18 while recording 720p on OBS Studio with empty firefox tabs in the background, Apple iPad Gen 11 has also been used to test this software compatibility, Newer iPads are able handle this software with in the safari web brower at 35 FPS which is the max speed!
